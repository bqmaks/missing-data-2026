## Сетки паттернов пропущенных значений

По поручению пользователя 2026-11-25 прочитан [раздел 4.1](https://stefvanbuuren.name/fimd/missing-data-pattern.html)
книги Stef van Buuren, Flexible Imputation of Missing Data, и визуально изучен
[рисунок 4.1](https://stefvanbuuren.name/fimd/fig/ch04-patterns-1.png).
Использован принцип оформления: плотные цветные ячейки, белые разделители,
общая рамка и серая полоса заголовка. В проекте созданы собственные SVG-схемы
10×4, с палитрой mice; книжное растровое изображение не включено в материалы.
Названия панелей заданы пользователем. Панель Unidentified – самостоятельный
пример с небольшим перекрытием: последние две переменные совместно наблюдаются
в одной строке. В заметках File Matching описан как крайний случай без таких
совместных наблюдений; общие полностью наблюдаемые переменные могут оставаться.
Малое перекрытие отделено от неидентифицируемости. В интерактиве два случая (D29).

Уточнения заметок 2026-11-25 проверены по первичным источникам:

- D’Orazio, Di Zio, Scanu, [Old and new approaches in statistical matching](https://www.istat.it/wp-content/uploads/2013/12/Old-and-new-approaches-in-statistical-matching.pdf), раздел 1: без совместных наблюдений связь не идентифицируется без дополнительных допущений, даже при наличии общих переменных.
- [SAS/STAT: Monotone Methods](https://support.sas.com/documentation/cdl/en/statug/68162/HTML/default/statug_mi_details06.htm): последовательная импутация по упорядоченным переменным; временная структура не требуется.
- [SAS/STAT: GEE, MISSMODEL](https://support.sas.com/documentation/cdl/en/statug/67523/HTML/default/statug_gee_syntax05.htm): пример реализации для монотонного выбывания; перемежающиеся пропуски не поддерживаются, MAR указано отдельно от требования к паттерну.

Аналогия File Matching с объединением без совпадающих идентификаторов
добавлена по диктовке пользователя. Поведение `full_join` проверено по
[официальной документации dplyr](https://dplyr.tidyverse.org/reference/mutate-joins.html):
сохраняются записи обеих таблиц; ключ объединения в примере явно задан как id.
