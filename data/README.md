# Воспроизводимый пример ИМТ–САД

Генерация: `Rscript scripts/generate_example.R` из корня проекта.
Та же генерация выполняется при сборке `index.qmd`.

1000 независимых пар из двумерного нормального распределения:
средние `(27, 135)`, SD `(4, 15)`, корреляция `0.6`, ковариация `36`.
`BMI` — ИМТ, `SBP` — САД. Только САД становится неполным.

| Файл | Содержание |
| --- | --- |
| `complete.csv` | Полные данные до удаления значений; id фиксирует одного и того же участника во всех вариантах. |
| `observed.csv` | Полностью наблюдаемый BMI и три версии SBP с NA: MCAR, MAR, MNAR. |
| `missingness.csv` | Индикаторы M (1 = пропуск) и индивидуальные вероятности пропуска. |
| `imputed.csv` | Девять заполненных таблиц в длинном формате: 3 механизма × 3 метода; наблюдаемые значения сохранены. |
| `estimates.csv` | 13 строк: полные данные и 3 механизма × (CC, mean, regression, stochastic). CC – полные случаи по переменным (D44): μ и SD ИМТ по всем наблюдаемым ИМТ, μ и SD САД по наблюдаемым САД, корреляция и регрессии по полным парам; `n` – число полных пар. |
| `truth.csv` | Истинные параметры распределения и обеих условных регрессий. |
| `metadata.R` | Параметры, все seeds, RNGkind и версия R; читается через `dget()`. |
| `pairwise-example.csv` | Отдельная конструкция из 12 строк для демонстрации не-PSD корреляционной матрицы. |

Механизмы: MCAR — вероятность 0.35; MAR — `plogis(-13 + 0.45 * BMI)`;
MNAR — `plogis(-17.1 + 0.12 * SBP)` по полному SBP до маскирования.
Пропуски генерируются независимыми Bernoulli, а не удалением ровно 35% строк.

Seed данных — 20261124; масок MCAR/MAR/MNAR — 20261125/26/27; шума
при стохастической импутации — 20261135/36/37. Seed не подбирался по результатам.
RNGkind: Mersenne-Twister / Inversion / Rejection.

В `estimates.csv` `n` — число строк анализа, `n_obs` — число реально измеренных
САД (полных пар), `missing_fraction` — исходная доля пропусков.
`intercept_SBP`, `slope_SBP` относятся к SBP ~ BMI; аналогичные поля BMI — к BMI ~ SBP.
SD использует знаменатель n−1. На слайдах значения округлены, в CSV сохранена
численная точность экспорта R. Это одна выборка, не средние по симуляциям.

Ни один метод импутации не использует скрытые истинные САД. Регрессия обучается
на полных парах; стохастический вариант добавляет независимый нормальный шум
с SD из `sigma(lm(...))` (n_obs−2 степеней свободы), без случайного выбора параметров.
Это одиночная импутация, не MI. Её SE и покрытие оценены в отдельном эксперименте ниже.

Учебная шестистрочная таблица для нотации на первых слайдах взята из PPTX и не
является подвыборкой этой симуляции. Таблица pairwise также отдельная иллюстрация.

IPW использует нормированные веса; дисперсии — взвешенные центральные моменты
с делителем Σw. ML использует n для дисперсии ИМТ и n_obs для остаточной дисперсии,
а не поправки n−1 или n_obs−2. EM сходится к тому же ML.

N(25,2²) для мужчин; SBP=95+BMI+12×male+N(0,8²); независимые 35% MCAR в поле пола.
Пример неразделимости: seed 20261152, Y и C независимо Bernoulli(.3).

## Monte Carlo

Запуск: `Rscript scripts/generate_simulation.R`. Seed 20261153; B=3000; исходный
DGP ИМТ–САД и MCAR/MAR/MNAR. Методы используют общие полные данные и маски внутри
репликации; Full повторён в строках трёх сценариев, но это одна и та же оценка.
Данные, маски и шум заново разыгрываются в каждой независимой репликации.

`bias` = средняя оценка − истина; `empirical_se` = SD оценок;
`mcse_mean` = empirical_se / sqrt(B); `mean_model_se` — средняя обычная SE.
95% ДИ для среднего: mean ± t_(n−1)·sd/sqrt(n); для наклона: OLS ± t_(n−2)·SE.
После импутации n=1000. Для IPW и ML интервалы здесь не построены, поля SE/покрытия — NA.

`coverage` — доля ДИ, содержащих истинный параметр; `mcse_coverage` =
sqrt(coverage·(1−coverage)/B). При нуле накрытий MCSE по этой формуле нулевая,
но верхняя односторонняя 95% граница покрытия примерно 3/B, а не ноль.
Округление применяется только при показе. В таблице слайдов «±» означает одну MCSE.

LOCF — отдельная аналитическая модель, а не ещё один метод заполнения сквозной
пары BMI/SBP. Её чистые JS-модели и seeds траекторий находятся в `widgets/locf-model.js`.
