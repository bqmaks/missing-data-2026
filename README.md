# missing-data-2026

Новая отправная точка для презентации и практических занятий по анализу данных
с пропущенными значениями. Учебного содержания пока нет: титульный слайд и пустой слайд для начала работы.

Используется Quarto-шаблон [fb-presentation](https://github.com/bqmaks/fb-presentation),
формат `material-revealjs`. Расширение скопировано без изменений с commit
`c1d3d0296e8a2fbf8fb64416060fea815b47513a`; лицензия —
[MIT](licenses/fb-presentation-MIT.txt).

## Локальная работа

Требуется Quarto; проверено с версией 1.10.18. Исходник слайдов — `index.qmd`.

```bash
quarto preview index.qmd --to material-revealjs
```

Сборка HTML в `_site/`:

```bash
quarto render index.qmd --to material-revealjs
```

Локальные входные материалы размещаются в `course-inputs/`, исключённой из Git.
Результаты сборки и кэши также не коммитятся.

## Публикация

Стартовый шаблон сохраняется в GitHub-репозитории. Дальнейшая разработка идёт
локально; в GitHub Pages разместим готовую презентацию по отдельному поручению.
Workflow автоматической публикации удалён, push сам по себе сайт не обновляет.
Прежняя реализация доступна в истории Git до этого стартового коммита.

Договорённости и состояние проекта: [wiki](wiki/Home.md), [AGENTS.md](AGENTS.md).
