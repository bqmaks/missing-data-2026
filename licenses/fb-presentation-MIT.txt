Design inspiration
------------------
The visual design of this template follows the MaterialBeamer theme for LaTeX
Beamer by Lorenzo Lancia (https://github.com/llancia/MaterialBeamer), which is
in turn based on the Radboud University Beamer theme by Pim Vullers.
MaterialBeamer is distributed under the LaTeX Project Public License and/or the
GNU General Public License.

The Typst and SCSS code in this repository is an independent reimplementation:
no code from MaterialBeamer was copied. Only the visual arrangement — bar
geometry, palette and typography — was reproduced.
