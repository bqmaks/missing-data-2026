  временно понята как отсутствие перемежающихся пропусков. Требование

  ответа пока нет. Паттерн и механизм пропусков в заметках разделены.

  Последовательная правка дошла до слайдов 7–8 и их заметок; дальнейшие
  изменения следуют очередным комментариям пользователя.

## Порядок работы

- В начале сессии читать [wiki/Session-handoff.md](wiki/Session-handoff.md), сверять его с Git и поручением пользователя.
- Перед содержательными изменениями читать [wiki/Home.md](wiki/Home.md), [решения](wiki/Decisions.md) и [статус плана](wiki/Lecture-plan.md).
- Проверять входные файлы командой `rg --files --hidden --no-ignore course-inputs/` и перечитывать актуальные версии. Папка игнорируется Git: `git status` не показывает внешние изменения.
- Пока учебных исходников нет, план сохраняет предварительный статус. Не восстанавливать удалённые материалы из истории или временной копии без поручения.
- Сами входные файлы изменять только по запросу пользователя. Актуальный источник — `course-inputs/missing_data_combined_v2.pptx` и `widgets-spec.md`; проверять состав папки перед каждой содержательной задачей.
- Прежние материалы использовать как источник для переработки после проверки научных формулировок и воспроизводимости примеров.
- Принятые решения отражать здесь и в wiki с датой, содержанием и причиной. При пересмотре сохранять историю в wiki.
- Отличать решение, проверенное состояние и предложение. Черновик не означает согласования.

## Шаблон и локальная сборка

HTML-формат — `material-revealjs`. Расширение `_extensions/material` скопировано без изменений с commit `c1d3d0296e8a2fbf8fb64416060fea815b47513a`.
`index.qmd` — редактируемый исходник. R-блоки при сборке создают пример, выгружают CSV и выводят таблицы/графики из одного объекта. Генератора текста слайдов нет.
Матрицы — LaTeX для локального MathJax 2.7.9 (версия, поддерживаемая установленным revealjs-форматом Quarto). Настройки лекции — в `assets/course.css`; общее расширение не изменено.

```bash
quarto preview index.qmd --to material-revealjs
quarto render index.qmd --to material-revealjs
```

Интерактивы — локальные ES-модули в `widgets/`, вариант 2.4 спецификации:
OJS в M0 обращался к CDN за marked. Просмотр интерактивов — через локальный HTTP,
не через `file://`. Статичные R-иллюстрации доступны в `?print-pdf`.

Результат сборки — `_site/`, исключённый из Git. Для готовой публикации нужен весь каталог с ресурсами.

При изменении общего шаблона:

1. Проверить состояние и инструкции репозитория шаблона; сохранить существующие изменения пользователя.
2. Общие исправления внести в шаблон, содержание курса оставить в проекте.
3. Проверить затронутые форматы сборкой и визуально.
4. Синхронизировать локальный шаблон, его GitHub-репозиторий и копию в проекте. Записать commit и результат в wiki; невыполненные шаги указывать явно.

## Проверка будущего содержания

- DGP и расчётные функции — `r/example.R`; отображение результатов — `r/slides.R`. Запуск без Quarto: `Rscript scripts/generate_example.R`; проверка: `Rscript tests/validate_example.R`. Данные и полные численные оценки — в `data/`.
- Дополнения: `Rscript tests/validate_advanced.R`; модели виджетов: `node --test tests/*.test.js`. Monte Carlo пересоздаётся командой `Rscript scripts/generate_simulation.R`, обычный render читает готовый `data/simulation-summary.csv`.
- Для вводного примера используется один фиксированный seed 20261124 без подбора; отдельные seeds масок и шума сохранены в `data/metadata.R`. Не переносить численные оценки из PPTX вручную. Одну реализацию не выдавать за оценку смещения или покрытия.
- Вычисления и практические файлы проверять запуском R; вёрстку — в браузере. Плотные слайды разбивать с сохранением содержания.
- Для таблиц покрытия нужны не менее 2000 репликаций, seed, параметры DGP и MCSE. Одна выборка не является оценкой среднего по симуляции.
- Неподтверждённые утверждения и непересчитанные числа отмечать явно.
- Не включать оценки SMC-FCS в итоговые таблицы при отказах rejection sampling.
- Сохранять согласованную нотацию: `M = 1` — пропуск, `C = 1 − M`, `n_obs` — полные пары, `m` — импутации, `ℓ` — номер импутации, `ψ` — параметры механизма. Не смешивать полные данные и полные случаи.
